Suporte remoto

Escolha o seu sistema, baixe e passe o ID e a senha para o técnico.

Windows

Windows 10 e 11
Baixar para Windows

Não precisa instalar para receber suporte.

  1. Clique em Baixar para Windows.
  2. Abra o arquivo baixado. Se o Windows avisar, clique em Mais informações → Executar assim mesmo.
  3. Informe ao técnico o ID e a senha que aparecem na tela.
  4. Quando ele conectar, clique em Aceitar.

Linux

Ubuntu, Debian, Mint e derivados (64 bits)
Baixar para Linux (.deb)

Ou instale pelo terminal:

curl -fsSL https://acesso.rafaelmarcolino.online/install.sh | sudo bash
  1. Abra o Terminal.
  2. Clique em Copiar, cole o comando no terminal e aperte Enter.
  3. Digite a senha do seu usuário quando o terminal pedir.
  4. No final, informe ao técnico o ID que aparece na tela.

Android
